# Ausgewählt aus den 789 Referenztests in css/CSS2/normal-flow/ (Dateien mit
# der Endung .xht oder .html und einem `<link rel="match">` oder
# `rel="mismatch"`). Ausgeschlossen ist ein Test, wenn er, seine Referenz
# oder ein Stylesheet, das eine der beiden mit `<link>` einbindet, eines der
# folgenden Muster enthält, ohne Rücksicht auf Groß- und Kleinschreibung und
# mit beliebigem Leerraum um `:`:
#
# - Skripte: `<script`
# - Ahem und Webschriften: `ahem`, `@font-face`
# - Floats: `float:`, `clear:`
# - Positionierung: `position:` mit `relative`, `absolute`, `fixed` oder
#   `sticky`
# - Tabellen: `display:` mit `table…` oder `inline-table…`, `<table`
# - Formulare: `<input`, `<button`, `<select`, `<textarea`
# - eingebettete Inhalte: `<object`, `<embed`, `<svg`, `<iframe`, `<video`,
#   `<canvas`
# - `overflow:` mit `hidden`, `scroll`, `auto` oder `clip`
# - Bidi: `direction: rtl`, `dir=`, `unicode-bidi`, `<bdo`
# - `writing-mode`, `transform:`, `run-in`
# - `@media`, `@import`
#
