# Rohdaten

Hier liegen Datensätze, die man nicht erfinden kann und die eigene Generatoren in Tabellen übersetzen, zum Beispiel die Unicode-Zeichendatenbank, CLDR oder die IANA-Zeitzonendatenbank (siehe `docs/architektur.md`, Abschnitt 1.1).

Jeder Datensatz bekommt einen eigenen Ordner mit

- den Rohdateien in genau einer, festgelegten Version,
- einer `HERKUNFT.md` mit Quelle (URL), Version, Abrufdatum und Lizenz.

Code gehört nicht hierher, nur Daten.
